## 验证方式与结果

- Vite 生产构建通过；保留现有主入口大于 500 kB 的体积提示。
- 隔离浏览器使用示例接口验证：跨页与跨 Tab 保留选择、最多 10 条、达到上限禁用未选项、单批提交与状态迁移。
- 验证部分失败、无停留事件、置信度为 0、依据展开、已保存结果、结果读取失败后的独立重载。
- 验证提交失败保留选择、状态同步中断后暂停轮询与手动恢复。
- 验证消息更新保留阅读位置、新结果提示、重新进入恢复进行中任务，以及离开页面后停止轮询。
- 验证格式工具的空值、无效值、零值和非标准依据记录；模型内容使用文本渲染。
- 1440px 桌面和 390px 窄屏检查通过，窄屏文档宽度等于视口宽度。
- 本地真实组件演示检查无页面脚本错误或 Vue 警告，未发出真实后端 API 请求。
- Git 差异空白检查通过。

验证未向生产环境发起 AI 分析，也没有触发实际事件复核操作。
